# Official integration references

Implementation checked against official sources retrieved during development (2026-10-26 Pacific). Live-account behavior remains to be verified.

* Deepgram official .NET SDK README and schemas: https://github.com/deepgram/deepgram-dotnet-sdk (Nova-3 streaming, linear16, interim_results, timestamps, confidence, diarize, endpointing, smart_format, keyterm, KeepAlive/CloseStream). Streaming wire endpoint: `wss://api.deepgram.com/v1/listen`. Raw PCM is 24 kHz mono signed little-endian 16-bit. `speech_final` is not treated as an automatic conversational turn. Documentation: https://developers.deepgram.com/reference/speech-to-text/listen-streaming (direct docs access blocked in development environment; official GitHub source was accessible).
* OpenRouter official docs mirror: https://github.com/OpenRouterTeam/docs (`quickstart.mdx`, `guides/overview/models.mdx`). `GET /api/v1/models` supplies exact IDs, output modalities and supported_parameters. `POST /api/v1/chat/completions` uses bearer authentication and messages; only advertised sampling/reasoning/token-limit parameters are sent. No static OpenRouter model IDs are guessed. https://openrouter.ai/docs/quickstart
* OpenAI official generated API schema: https://github.com/openai/openai-node/blob/master/src/resources/realtime/realtime.ts. GA `gpt-realtime` is listed. Uses `session.update` with `type: realtime`, `output_modalities: [text]`, `audio.input.format: { type: audio/pcm, rate: 24000 }`, manual turn detection, `input_audio_buffer.append/commit`, `response.create`, `response.done`, and out-of-band input item references. Canonical history/context is injected with every response, including after reconnect. https://developers.openai.com/api/docs/guides/realtime

Connection tests: Deepgram authenticated project listing, OpenRouter key introspection, OpenAI model listing. These test credential connectivity, not inference entitlement for every route. They intentionally do not process meeting content or generate billable responses. Provider privacy/retention policies apply independently of local no-audio-recording behavior.
